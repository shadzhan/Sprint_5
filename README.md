# Sprint_5
Автоматизированное тестирование сайта Stellar Burgers

## Описание проекта

Данный проект представляет собой набор автоматических тестов для проверки ключевой функциональности сайта Stellar Burgers с использованием Python, Selenium и pytest. Цель — автоматизировать сценарии регистрации, входа, навигации по сайту и выхода из аккаунта, а также проверки переходов внутри раздела "Конструктор".

## Структура проекта

Sprint_5/
├── tests/
│   ├── test_constructor.py    # Тесты конструктора
│   ├── test_login.py          # Тесты входа
│   ├── test_profile.py        # Тесты личного кабинета
│   └── registration.py        # Тесты регистрации
├── locators.py                 # Локаторы элементов сайта
├── helpers.py                  # Вспомогательные функции (генерация email и пароля)
├── README.md                   # Описание проекта
├── .gitignore                  # Исключения для git

Тестовые сценарии
Регистрация
Проверка валидации полей (имя, email, пароль).
Обработка ошибок для некорректных данных.
Авторизация
Вход через разные разделы приложения.
Восстановление пароля.
Личный кабинет
Навигация между разделами.
Обновление профиля.
Выход из системы.
Конструктор бургеров
Переключение между разделами (Булки, Соусы, Начинки)
